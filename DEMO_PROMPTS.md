## 📋 Exact Prompts to Use (in order)

### Prompt 1: Initial Research Request
```
I have an upcoming sales meeting with [COMPANY NAME]. Can you help me prepare by:
1. Getting their company overview and tech stack insights from Enlyft
2. Checking if we have any existing engagement history in HubSpot
3. Finding key decision makers I should reach out to
4. Drafting a personalized outreach email

Let's start with the company research.
```

---

### Prompt 2: Generate Insights
```
Based on this research, what are the top 3 insights I should bring to the meeting? Focus on opportunities where our product could help them.
```

---

### Prompt 3: Find Decision Makers
```
Now find the key decision makers at [COMPANY NAME] that I should connect with - specifically those involved in [data engineering/sales operations/marketing technology].
```

**Department suggestions:**
- Data engineering
- Sales operations
- Marketing technology
- RevOps
- Analytics

---

### Prompt 4: Draft Email
```
Draft a personalized email to [DECISION MAKER NAME] that:
- References the insights we discovered
- Mentions their specific tech stack
- Proposes a brief call to discuss how we can help
- Keep it concise and value-focused (under 150 words)
```

---

### Prompt 5: Send Email
```
Send this email to [EMAIL ADDRESS] with subject: "Quick question about [RELEVANT TOPIC]"
```

---

## 🎤 One-Liner Talking Points

**While Claude processes each step:**

1. **During research:** "Claude is querying Enlyft and HubSpot in parallel - normally I'd need to open 3 different tools"

2. **After data appears:** "Look at this - complete tech stack, company size, and engagement history in seconds"

3. **During insight generation:** "Now it's analyzing patterns to surface strategic talking points"

4. **After insights:** "These aren't just facts - they're actionable insights I can use immediately"

5. **During contact search:** "Finding decision makers across departments and seniority levels"

6. **After email draft:** "Notice how personalized this is - it references their actual tech stack"

7. **After sending:** "Done. Research to outreach in under 5 minutes."

## 🆘 Troubleshooting

**If MCP server doesn't respond:**
- "Let me retry that query" (rephrase slightly)
- Continue with narrative: "Normally it's instant, but..."

**If you get generic response:**
- Add: "Please use the Enlyft MCP server to get real data for [COMPANY]"

**If email send fails:**
- "For today's demo, let's review the email instead of sending to production"
- Show the draft and move to closing

**Nuclear option:**
- Have screenshots of a successful run ready
- "Let me show you what this looks like in production"
